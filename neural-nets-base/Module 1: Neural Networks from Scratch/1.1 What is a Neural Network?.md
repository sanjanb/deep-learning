## **1.1 What is a Neural Network?**

### **1. Intuition**

* **Explain like I'm 15:** Imagine you want to train a computer to recognize if a house is overpriced. You feed it features like the number of bedrooms and square footage (**Inputs**). To make a guess, the computer assigns a level of importance to each feature (**Weights**). It multiplies the features by their importance, adds a constant baseline slider to adjust how easily it jumps to a conclusion (**Bias**), and bundles this math into a processing node (**Neuron**). By stacking these processing nodes side-by-side (**Layers**), the computer handles increasingly complex logic, eventually outputting a single prediction (**Outputs**), like the estimated price.

### **2. Mathematics**

A single biological-inspired neuron computes a linear combination of its inputs followed by a non-linear squashing function (activation function, e.g., $\tanh$ or ReLU):

$$z = \sum_{i} (x_i \cdot w_i) + b$$

$$a = \text{activation}(z) = \tanh(z)$$

Where:

* $x_i$: Input feature scalars.
* $w_i$: Synaptic weights determining specific feature scaling.
* $b$: Bias adjusting the trigger threshold of the neuron.
* $\tanh(z) = \frac{e^{2z} - 1}{e^{2z} + 1}$: Non-linear activation bounding outputs between $-1$ and $+1$.

### **3. Code**

```python
import math

class Value:
    """ Stores a single scalar value and its gradient """
    def __init__(self, data, _children=(), _op='', label=''):
        self.data = data
        self.grad = 0.0  # Represents the derivative of the loss w.r.t this value
        self._prev = set(_children)
        self._op = _op
        self.label = label
        self._backward = lambda: None

    def __add__(self, other):
        other = other if isinstance(other, Value) else Value(other)
        out = Value(self.data + other.data, (self, other), '+')
        
        def _backward():
            self.grad += 1.0 * out.grad
            other.grad += 1.0 * out.grad
        out._backward = _backward
        return out

    def __mul__(self, other):
        other = other if isinstance(other, Value) else Value(other)
        out = Value(self.data * other.data, (self, other), '*')
        
        def _backward():
            self.grad += other.data * out.grad
            other.grad += self.data * out.grad
        out._backward = _backward
        return out

    def tanh(self):
        x = self.data
        t = (math.exp(2*x) - 1) / (math.exp(2*x) + 1)
        out = Value(t, (self,), 'tanh')
        
        def _backward():
            self.grad += (1 - t**2) * out.grad
        out._backward = _backward
        return out

```

### **4. Architecture Diagram**

$$\begin{array}{rcccl}
\text{Inputs }(x_1, x_2) & \longrightarrow & \text{Weights }(w_1, w_2) & & \\
& & \searrow \quad \swarrow & & \\
\text{Bias }(b) & \longrightarrow & \boxed{\sum (x_i \cdot w_i) + b} & \longrightarrow & \boxed{\tanh} \longrightarrow \text{Output }(a)
\end{array}$$

### **5. Interview Questions**

1. **Why do we need a bias term in a neuron?**
* *Answer:* Without a bias term, if all inputs ($x$) are zero, the output of the linear combination will always be zero, regardless of the weights. The bias shifts the activation function left or right, allowing the network to fit patterns that do not pass precisely through the origin.


2. **What happens if you don't use an activation function (like $\tanh$) in a multi-layer neural network?**
* *Answer:* The entire network collapses into a single linear transformation. Matrix multiplication of linear layers stacked together is mathematically equivalent to a single linear layer, preventing the network from learning non-linear relationships.



### **6. Common Mistakes**

* **Forgetting to accumulate gradients (`+=`):** If a single variable is used multiple times in a forward pass, its gradient will be overwritten during backpropagation if you use `=` instead of accumulating with `+=`.

### **7. Connections to GPT**

* Large Language Models like GPT-4 operate on this exact foundation. Instead of passing individual `Value` scalars sequentially, GPT packages millions of inputs, weights, and biases into massive matrices (Tensors) processed in parallel on GPUs to maintain structural efficiency.

## **1.2 Computational Graphs**

### **1. Intuition**

* **Explain like I'm 15:** Think of a computational graph like a factory assembly line blueprint. Every raw material statement is a starting point. Every assembly machine represents an operation (like adding or multiplying). The arrows show how parts move along the line until the final finished product comes out the other end. Tracking this path step-by-step makes it simple to trace the final product's quality defects back to the exact machine or material that caused them.

### **2. Mathematics**

A computational graph $\mathcal{G} = (\mathcal{V}, \mathcal{E})$ consists of:

* **Nodes ($\mathcal{V}$):** Representing variables (values) or operational steps ($+, *, \tanh$).
* **Edges ($\mathcal{E}$):** Directed arrows conveying the data dependencies.

During the **Forward Pass**, computations travel along the topological sorting sequence of the graph from input leaves to output roots:

$$\text{If } v_1 = f(u_1, u_2), \text{ then } \text{Forward}(v_1) \text{ evaluates } f(u_1, u_2)$$

### **3. Code**

```python
def build_topo(v, visited, topo):
    if v not in visited:
        visited.add(v)
        for child in v._prev:
            build_topo(child, visited, topo)
        topo.append(v)

# Executing backpropagation over the entire graph sequentially
def backward(root):
    topo = []
    visited = set()
    build_topo(root, visited, topo)
    
    root.grad = 1.0 # Base case: derivative of output w.r.t itself is always 1
    for node in reversed(topo):
        node._backward()

```

### **4. Architecture Diagram**

$$\boxed{a} \cdot \boxed{b} \longrightarrow \boxed{\text{Node }(*)} \xrightarrow{\quad \text{Edge} \quad} \boxed{c} \xrightarrow{\quad +d \quad} \boxed{\text{Output Node}}$$

### **5. Interview Questions**

1. **How does reverse-mode automatic differentiation leverage a computational graph?**
* *Answer:* It executes a forward pass to compute intermediate node values, caches these states, and then traverses the graph in reverse topological order to apply the chain rule and determine gradients efficiently.



### **6. Common Mistakes**

* **Graph Cycles:** Computational graphs for backpropagation must be Directed Acyclic Graphs (DAGs). Introducing loops breaks topological sorting, causing infinite recursive cycles.

### **7. Connections to GPT**

* PyTorch dynamically compiles a massive computational graph behind the scenes when running GPT models. Every token generation step expands or traverses this graph structure to adjust attention weights.

## **1.3 Derivatives and Gradients**

### **1. Intuition**

* **Explain like I'm 15:** Imagine you are standing on a foggy mountain and want to know which way leads up. If you step slightly to the right, you notice you rise a little bit. The **derivative** tells you exactly how much your altitude changes for that tiny step. The **gradient** is simply a collection of these values for every direction, pointing you exactly along the steepest path up the mountain.

### **2. Mathematics**

The derivative measures the instantaneous rate of change of a function output with respect to an input:

$$f'(x) = \lim_{h \to 0} \frac{f(x+h) - f(x)}{h}$$

In a computational graph, backpropagation evaluates the global gradient via the **Chain Rule**. If an output $L$ depends on $y$, which depends on $x$:

$$\frac{\partial L}{\partial x} = \frac{\partial L}{\partial y} \cdot \frac{\partial y}{\partial x}$$

Where $\frac{\partial y}{\partial x}$ is the **Local Derivative** of the operation, and $\frac{\partial L}{\partial y}$ is the upstream gradient flowing back from the output.

### **3. Code**

```python
# Numerical verification of a derivative
def f(x):
    return 3*x**2 - 4*x + 5

h = 0.000001
x = 3.0
numerical_derivative = (f(x + h) - f(x)) / h
print(f"Numerical approximation: {numerical_derivative}") 
# Output aligns with analytical solution: 6(3) - 4 = 14

```

### **4. Architecture Diagram**

$$\frac{\partial L}{\partial y} \text{ (Upstream Gradient)} \longrightarrow \boxed{\text{Operation: } y=f(x)} \longrightarrow \text{Local Derivative: } \frac{\partial y}{\partial x}$$

$$\text{Result: } \frac{\partial L}{\partial x} = \frac{\partial L}{\partial y} \cdot \frac{\partial y}{\partial x}$$

### **5. Interview Questions**

1. **What is the difference between an analytical derivative and a numerical derivative?**
* *Answer:* An analytical derivative uses symbolic calculus rules to find an exact formula for the slope, while a numerical derivative estimates it by calculating the change over a tiny step ($h$). Deep learning libraries use analytical rules inside their backpropagation passes for speed and precision.



### **6. Common Mistakes**

* **Vanishing Gradients:** Using activation functions with flat outer regions (like extreme values on the $\tanh$ curve) yields local derivatives very close to $0$. Multiplying by these values during backpropagation dampens the upstream gradient, preventing earlier layers from updating.

### **7. Connections to GPT**

* When training a model like GPT, billions of parameters are adjusted at once using gradients. The model uses the chain rule to update its weights, steering the entire system toward generating more accurate tokens.
